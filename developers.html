Authentication

            
curl -H "Authorization: Bearer agt_live_YOUR_KEY" \
  "BASE/v1/jaipur/zones?limit=10"

            
Or send the key as X-API-Key. Rate limits, row caps and credits come back in the response and headers (X-Credits-Remaining).

          
Endpoints

          
Python

            
import requests
r = requests.get("BASE/v1/jaipur/cells",
                 params={"lat": 26.92, "lng": 75.79, "radius_m": 1500, "attrs": "residents,retail_places"},
                 headers={"Authorization": "Bearer agt_live_YOUR_KEY"})
print(r.json()["data"][:3], r.headers["X-Credits-Remaining"])

          
Credits and errors

            
  • Credits = rows × weight ÷ 10, rounded up. Weight: base 1, derived 3, decision 5. Exports are half price.
    • 
              
  • 401 bad key · 402 out of credits · 403 not in your plan (city, layer or attribute) · 429 rate or daily limit.
    • 
              
  • Page with limit and offset; meta.next_offset is null on the last page.
    • 
              
  • Every response carries a licence field. Attribution is required; resale is not permitted.
    • 
              
  • Voter-roll, booth-level and person-level data are never offered.
